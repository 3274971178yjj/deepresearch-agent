项目经历   DeepResearch Agent：多智能体深度研究系统（自研异步编排引擎）      2026.06—2026.09
技术栈：Python · asyncio · DAG 拓扑调度 · 有限状态机 · 多后端 LLM 路由 · SQLite ·
        NumPy 向量检索 · sentence-transformers · TextRank · aiohttp · Bootstrap 统计检验

· 项目价值
  深度研究任务存在信息过载、多步推理断裂、幻觉漂移三大痛点，且普遍缺乏端到端评测手段。
  我从零构建了一套多 Agent 系统，把模糊问题自动转化为约 2 万字、带引用的深度研究报告，
  并配套可复现的三层评测流水线。

· 自研异步编排引擎
  — 基于 asyncio 实现 DAG 拓扑分层并发调度，用信号量控制并发度为 5；以 9 状态状态机
    显式管理任务生命周期。
  — 三级降级保证长链路不中断：单任务超时即标记继续、不阻塞整层 → 失败率超 50% 触发
    增量重规划（仅重做失败子任务，上限 3 轮）→ 全局超时 600 秒则用已有结果强制合成。

· Red-Blue 对抗降噪
  — Red Agent 从事实核查、幻觉检测、逻辑一致性、来源可信度、覆盖完整度五个维度加权
    评分并定位问题，其中事实类维度权重合计 0.55。
  — Blue Agent 按问题类型执行就地修正、补充检索、整段移除三类修复；设收敛与震荡双重
    刹车，已修复问题复现即终止。
  — 对模型输出做多级 JSON 解析兜底，解析失败降级为保守评分，保证对抗循环不中断。

· 上下文压缩与共享记忆
  — 按上下文预算占用率自动分级触发三级压缩：向量相关性粗筛 → TextRank 关键句抽取 →
    LLM 层级摘要，超限再由滑动窗口兜底；前两级为抽取式，不引入生成误差。
  — 共享记忆基于 SQLite + NumPy 向量检索实现，写入前做语义去重与矛盾检测，冲突由
    多数投票、来源权重、LLM 裁定三种策略消解。

· 端到端评测体系
  — 自建 ResearchBench（11 个领域、35 道题）+ HotpotQA 深度研究变体。
  — 三层指标：规则指标（事实准确率、幻觉率、引用覆盖率、逻辑一致性、完备性）、
    LLM-as-Judge 多维评分、统计检验（Bootstrap 95% 置信区间、Cohen's d、配对 t 检验）。
  — 配 7 项一键实验脚本支持模块消融；已对实际产出报告完成指标实测与区分度校验，规则
    口径幻觉率 3.34%。
