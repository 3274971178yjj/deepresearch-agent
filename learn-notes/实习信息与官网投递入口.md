## 二、官网投递 vs BOSS直聘：两条都要走

| | 官网/校招系统投递 | BOSS直聘 |
|---|---|---|
| **速度** | 慢（网申 → 筛选 → 通知，常 1–2 周） | **快**（直接和技术负责人 / HR 对话，当天有回复） |
| **覆盖面** | 大厂基本**只在官网收**（腾讯、华为、微众、平安…） | 中小厂、创业公司主力 |
| **简历版本控制** | 每投一家可选不同版本 ✅ | 一份简历走天下 ⚠️ |
| **反馈** | 常无回音 | 有"已读"回执，**是判断简历过不过关的最好信号** |
| **适合** | 大厂、国企、银行、制造业 | 小厂、创业公司、快速练手 |

**结论：两条并行。** 官网投大厂（那 15 家左右），BOSS 投其余的，练手也走 BOSS。

## 四、BOSS直聘 操作手册（照着做）

### 4.1 先设置（一次性，5 分钟，之后省几十次）

1. **在线简历完善度打到 100%** —— BOSS 上完善度低的简历曝光权重低
2. **设置"打招呼语"**：BOSS 有官方的打招呼语设置（我的 → 打招呼语）。把下面第五节的话术粘进去
3. **设置求职意向**：深圳 / 算法实习生 / 大模型 / 薪资写"面议"或按实习行情填
4. **打开"简历可见"** —— 让 HR 能主动找到你（被动曝光也是量）

### 4.2 搜索关键词清单（**别只搜"大模型实习"**）

深圳的岗位供给结构决定了你要放宽搜索词。按优先级：

```
第一组（高对口）
  算法实习生
  LLM 实习生 / 大模型实习生
  Agent 实习生 / 智能体 实习生
  NLP 实习生

第二组（覆盖面大，命中率更高）
  算法工程师（实习）
  AI 应用 实习生
  RAG / 检索增强 实习生
  Python 算法 实习生

第三组（补充）
  机器学习 实习生
  数据算法 实习生
  AI 工程师 实习生
```

**加筛选**：城市=深圳 / 经验=在校生 / 学历=本科及以上 / 薪资范围不设限。

### 4.3 每日操作节奏（官方额度内，合规）

```
① 早上：搜第一组关键词 → 按"最新"排序 → 投当天新发的岗位（新岗位回复率最高）
② 用满 150 次/日的打招呼上限（BOSS 官方额度，这是规则允许的上限）
③ 已读不回的：隔 3–5 天用一句新话术补一次（不要重复粘同一句）
④ 晚上：更新追踪表，记录"已读/未读"——这是判断简历过不过关的关键信号
```

⚠️ **不要用脚本。** 理由详见 [实习投递清单](实习投递清单-深圳大模型与Agent.md) 第六节：
官方额度内手动操作是合规的，脚本会撞平台风控，且你 BOSS 账号被封 = 主渠道直接没了。

**"已拒"的原因是最值钱的反馈，一定要记。** 连续三家拒在同一个点上，那就是你简历里的一个真问题。
